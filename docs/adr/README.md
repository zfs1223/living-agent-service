# ADR（Architecture Decision Records）

本目录用于沉淀关键架构决策，确保“为什么这样做”可追溯。

## 使用规则

1. 每个 ADR 一个文件，命名格式：`ADR-xxxx-短标题.md`
2. 编号递增（`0001` 开始）
3. 重大架构变更必须有 ADR（例如：核心抽象变更、跨模块重构、基础设施替换）
4. ADR 状态允许：提议 / 已接受 / 已拒绝 / 已废弃 / 已替换
5. PR 如涉及架构决策，必须在 PR 模板中填写 ADR 链接

## 快速开始

1. 复制模板：`ADR-0000-template.md`
2. 新建文件：`ADR-0001-xxx.md`
3. 在 PR 中引用该 ADR
