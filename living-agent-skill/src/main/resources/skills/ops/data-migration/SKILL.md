# Data Migration

> 数据迁移技能，实现数据库和数据的迁移管理（闭环62）

## 一、技能描述

数据迁移技能使运维部数字员工能够：
- 迁移计划制定和执行
- 数据一致性验证
- 迁移回滚机制
- 迁移审计记录

## 二、适用编制

| 编制代码 | 职位 | 主要用途 |
|---------|------|---------|
| T04 | DevOps工程师 | 执行迁移 |
| T05 | 运维工程师 | 迁移监控 |
| O01 | 数据分析师 | 数据验证 |

## 三、触发词

- 数据迁移、migration
- 数据库迁移、schema迁移
- 迁移验证、迁移回滚

## 四、核心功能

### 4.1 迁移生命周期

```
检测 → 计划 → 迁移 → 验证 → 切换 → 回滚(可选) → 审计
```

### 4.2 迁移类型

| 类型 | 描述 | 风险等级 |
|------|------|---------|
| Schema迁移 | 表结构变更 | 中 |
| 数据迁移 | 数据迁移 | 高 |
| 版本升级 | 数据库版本升级 | 高 |
| 平台迁移 | 跨数据库平台迁移 | 极高 |

### 4.3 验证策略

| 验证项 | 方法 | 通过条件 |
|-------|------|---------|
| 数据量 | 计数对比 | 100%一致 |
| 数据内容 | 校验和对比 | 100%一致 |
| 索引完整性 | 索引检查 | 无缺失 |
| 约束验证 | 约束测试 | 全部通过 |
| 应用兼容 | 功能测试 | 无报错 |

### 4.4 回滚机制

| 场景 | 回滚策略 |
|------|---------|
| 迁移失败 | 恢复备份 |
| 验证失败 | 回滚到源库 |
| 应用不兼容 | 切回旧版本 |
| 性能下降 | 优化后重试 |

## 五、使用示例

### 5.1 制定迁移计划

```
用户: 制定数据库迁移计划

技能执行:
1. 分析源库结构
2. 评估数据量和迁移时间
3. 制定迁移步骤
4. 设计验证方案
5. 准备回滚预案
6. 返回迁移计划
```

### 5.2 执行迁移

```
用户: 执行数据迁移

技能执行:
1. 创建数据快照
2. 执行数据迁移
3. 验证数据一致性
4. 执行切换
5. 监控应用状态
6. 记录迁移结果
```

### 5.3 验证迁移结果

```
用户: 验证迁移是否成功

技能执行:
1. 对比数据量
2. 计算数据校验和
3. 检查索引和约束
4. 执行功能测试
5. 生成验证报告
```
