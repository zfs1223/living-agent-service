# 客服部岗位职责

**制度编号**: HR-11

**版本**: v1.0

**最后更新**: 2026-04-14

---

## 1. 部门概述

### 1.1 部门定位

客服部是公司客户服务的核心部门，负责客户问题处理、客户关系维护、需求收集反馈，与 CsBrain 深度协同，通过数字员工提升客服效率。

### 1.2 部门使命

提升客户满意度，建立客户信任，驱动产品优化。

### 1.3 组织架构

```
客服部
├── 客服主管 (M1)
│   ├── 客服组长 (P3)
│   │   ├── 高级客服专员 (P2)
│   │   └── 客服专员 (P1/P2)
│   └── 客服专员 (若干)
```

---

## 2. 核心岗位职责

### 2.1 客服主管

**向谁汇报**: 总经理

**核心职责**:
1. 制定客服策略，提升客户满意度
2. 统筹客服团队管理，确保服务质量
3. 处理重大客户投诉，管控危机事件
4. 分析客户需求，推动产品改进

**具体工作任务**:
- 客服策略制定 (年度)
- 团队绩效管理 (每月)
- 重大投诉处理 (按需)
- 客户满意度分析 (每月)

**任职要求**:
- 学历：大专及以上
- 经验：5年以上客服经验，2年以上管理经验
- 能力：客户服务、团队管理、问题解决
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 客户满意度 | ≥90% |
| 问题解决率 | ≥85% |
| 投诉解决率 | 100% |
| 团队流失率 | ≤15% |

### 2.2 客服组长

**向谁汇报**: 客服主管

**核心职责**:
1. 带领小组完成客服任务
2. 监控服务质量，辅导组员提升
3. 处理复杂客户问题
4. 收集分析客户反馈

**具体工作任务**:
- 小组日常运营 (每日)
- 组员绩效跟踪 (每周)
- 疑难问题处理 (持续)
- 客户反馈分析 (每周)

**协作关系**:
- 内部：客服组
- 外部：技术部(问题反馈)、运营部(用户运营)

**任职要求**:
- 学历：大专及以上
- 经验：3年以上客服经验，1年以上带团队经验
- 能力：客户服务、问题解决、团队辅导
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 小组满意度 | ≥90% |
| 小组问题解决率 | ≥85% |
| 响应速度 | ≤30秒 |

### 2.3 客服专员 (各级)

**向谁汇报**: 客服组长

**核心职责**:
- P2 (高级): 复杂问题处理、新人带教、质检支持
- P1/P2 (中级/初级): 客户咨询回复、问题记录、简单问题解决

**具体工作任务**:
- 客户在线咨询回复 (每日)
- 问题记录与分类 (持续)
- 简单问题解决 (持续)
- 客户信息更新维护 (持续)
- 与 CsBrain 协作进行智能客服 (持续)

**协作关系**:
- 内部：客服组
- 外部：技术部(问题升级)、运营部(反馈同步)

**任职要求**:
| 级别 | 学历 | 经验 | 能力 |
|------|------|------|------|
| P2 | 大专+ | 2年+ | 独立处理复杂问题 |
| P1 | 大专 | 应届/1年 | 良好沟通能力 |

**权限级别**:
- P2: DEPARTMENT
- P1: LIMITED

**考核指标**:
| 指标 | 权重 |
|------|------|
| 客户满意度 | 30% |
| 问题解决率 | 30% |
| 响应速度 | 20% |
| 质检评分 | 20% |

## 3. 数字员工协作规范

### 3.1 客服部数字员工矩阵

| 数字员工 | 技能 | 协作场景 | 人类员工角色 |
|---------|------|---------|-------------|
| cs-agent-001 | 智能客服 | 常见问题解答、问题分类 | 人工处理复杂问题 |
| ticket-manager-001 | 工单管理 | 工单创建、跟踪、升级 | 人工决策升级 |
| sentiment-analyzer-001 | 情绪分析 | 客户情绪识别、投诉预警 | 人工安抚处理 |
| knowledge-base-001 | 知识库 | FAQ更新、答案推荐 | 人工审核确认 |

### 3.2 人机协作流程

```
客户咨询进入
    ↓
cs-agent-001 智能接待，识别意图
    ↓
├─ 简单问题 → 直接解答 → 客户满意 → 归档
    ↓
└─ 复杂问题 → 人工接管 → 客服专员处理
    ↓
情绪异常 → sentiment-analyzer-001 预警
    ↓
客服组长关注 → 必要时升级
    ↓
问题解决 → 知识库-001 更新FAQ
```

## 4. 客服规范与流程

### 4.1 服务标准

| 服务类型 | 响应时效 | 处理时效 | 服务渠道 |
|---------|---------|---------|---------|
| 即时咨询 | ≤30秒 | 即时 | 在线 |
| 普通问题 | ≤5分钟 | ≤2小时 | 在线/工单 |
| 投诉问题 | ≤1小时 | ≤24小时 | 工单/电话 |
| 紧急问题 | ≤5分钟 | ≤4小时 | 电话优先 |

### 4.2 问题分级

| 级别 | 定义 | 处理流程 |
|------|------|---------|
| L1 | 简单咨询，有标准答案 | cs-agent-001 直接解答 |
| L2 | 一般问题，需人工处理 | 客服专员处理 |
| L3 | 复杂问题，需技术协助 | 技术部介入 |
| L4 | 重大投诉/危机事件 | 升级至管理层 |
