# 法务部岗位职责

**制度编号**: HR-13

**版本**: v1.0

**最后更新**: 2026-04-14

---

## 1. 部门概述

### 1.1 部门定位

法务部是公司法律合规的核心部门，负责合同审核、法律咨询、合规管理、风险控制，与 LegalBrain 深度协同，实现法务数字化管理。

### 1.2 部门使命

防范法律风险，保障合规经营，为公司决策提供法律支持。

### 1.3 组织架构

```
法务部
├── 法务总监 (M3)
│   ├── 高级法务专员 (P3)
│   │   ├── 法务专员 (P2)
│   │   └── 法务助理 (P1)
```

---

## 2. 核心岗位职责

### 2.1 法务总监

**向谁汇报**: 总经理

**核心职责**:
1. 制定法务战略，保障公司合规经营
2. 统筹法务团队建设，提升法务能力
3. 管理重大法律事务，防范重大风险
4. 参与公司战略决策，提供法律支持

**具体工作任务**:
- 法务战略制定 (年度)
- 重大法律事务处理 (按需)
- 外部律师资源管理 (持续)
- 向管理层汇报法务状况 (季度)

**任职要求**:
- 学历：本科及以上，法律相关专业
- 资格：法律职业资格证
- 经验：10年以上法务经验，5年以上管理经验
- 能力：法律专业、风险管控、决策支持
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 法律风险事件 | 零重大风险 |
| 合同审核及时率 | ≥98% |
| 合规培训覆盖率 | 100% |
| 法律成本控制 | 预算内 |

### 2.2 高级法务专员

**向谁汇报**: 法务总监

**核心职责**:
1. 审核重大合同，管控法律风险
2. 处理复杂法律事务
3. 指导初中级法务人员
4. 推动合规体系建设

**具体工作任务**:
- 重大合同审核 (持续)
- 法律意见书出具 (持续)
- 复杂纠纷处理 (按需)
- 合规体系建设 (年度)

**协作关系**:
- 内部：各部门
- 外部：外部律师、司法机关、监管机构

**任职要求**:
- 学历：本科及以上，法律相关专业
- 资格：法律职业资格证
- 经验：6年以上法务经验
- 能力：法律专业、风险识别、沟通协调
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 合同审核准确率 | 100% |
| 法律意见采纳率 | ≥95% |
| 风险预警及时性 | ≥90% |

### 2.3 法务专员

**向谁汇报**: 高级法务专员/法务总监

**核心职责**:
- P2 (中级): 常规合同审核、法律咨询、日常法务支持
- P1 (助理): 辅助审核、文档管理、资料整理

**具体工作任务**:
- 常规合同审核 (持续)
- 法律咨询回复 (持续)
- 法律文件归档 (持续)
- 法规政策收集 (持续)
- 与 LegalBrain 协作进行智能合同审查 (持续)

**协作关系**:
- 内部：各部门
- 外部：外部律师、客户法务

**任职要求**:
| 级别 | 学历 | 资格 | 经验 |
|------|------|------|------|
| P2 | 本科+ | 法律职业资格证 | 3年+ |
| P1 | 本科 | 通过司法考试优先 | 应届/1年 |

**权限级别**:
- P2: DEPARTMENT
- P1: LIMITED

**考核指标**:
| 指标 | 权重 |
|------|------|
| 审核及时率 | 30% |
| 审核准确率 | 40% |
| 工作质量 | 20% |
| 协作满意度 | 10% |

## 3. 数字员工协作规范

### 3.1 法务部数字员工矩阵

| 数字员工 | 技能 | 协作场景 | 人类员工角色 |
|---------|------|---------|-------------|
| contract-reviewer-001 | 合同审查 | 条款识别、风险标注 | 人工风险判断 |
| compliance-checker-001 | 合规检查 | 制度合规、业务合规 | 人工决策 |
| legal-research-001 | 法律检索 | 法规查询、案例分析 | 人工分析应用 |
| document-generator-001 | 文档生成 | 法律文书、合同模板 | 人工审核确认 |

### 3.2 人机协作流程

```
合同提交
    ↓
contract-reviewer-001 智能审查，标注风险条款
    ↓
法务专员人工复核
    ↓
├─ 常规合同 → 法务专员审核 → 通过/修改
    ↓
└─ 重大合同 → 高级法务专员审核 → 通过/修改
    ↓
法务总监审批 (重大合同)
    ↓
合规检查 → compliance-checker-001 复查
    ↓
签约归档
```

## 4. 法务规范与流程

### 4.1 合同审核流程

```
合同提交 → 初步审核 → 风险标注 → 沟通修改 → 审核通过 → 签署归档
```

### 4.2 审核时效

| 合同类型 | 审核时效 |
|---------|---------|
| 常规合同 | ≤2个工作日 |
| 复杂合同 | ≤5个工作日 |
| 紧急合同 | ≤1个工作日 |
| 重大合同 | ≤7个工作日 |

### 4.3 风险分级

| 级别 | 定义 | 处理方式 |
|------|------|---------|
| 高风险 | 重大权利义务、潜在纠纷 | 法务总监审核 |
| 中风险 | 需关注条款 | 高级法务专员审核 |
| 低风险 | 标准条款 | 法务专员审核 |
