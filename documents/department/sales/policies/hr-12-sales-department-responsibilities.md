# 销售部岗位职责

**制度编号**: HR-12

**版本**: v1.0

**最后更新**: 2026-04-14

---

## 1. 部门概述

### 1.1 部门定位

销售部是公司收入增长的核心驱动部门，负责市场拓展、客户开发、销售达成、合同签订，与 SalesBrain 深度协同，实现销售效率提升。

### 1.2 部门使命

实现销售业绩增长，建立稳固客户关系，打造行业品牌。

### 1.3 组织架构

```
销售部
├── 销售总监 (M3)
│   ├── 销售组
│   │   ├── 销售经理 (M1/M2)
│   │   ├── 高级销售代表 (P3)
│   │   └── 销售代表 (P2)
│   └── 市场组
│       ├── 市场经理 (M1)
│       └── 市场专员 (P2)
```

## 2. 核心岗位职责

### 2.1 销售总监

**向谁汇报**: 总经理

**核心职责**:
1. 制定销售战略，实现业绩目标
2. 统筹销售团队建设，培养销售人才
3. 管理重点客户，突破大客户合作
4. 协调跨部门资源，推动销售进程

**具体工作任务**:
- 销售战略制定 (年度)
- 销售目标分解 (季度)
- 重点客户拜访 (按需)
- 向管理层汇报销售进展 (每月)

**任职要求**:
- 学历：本科及以上
- 经验：8年以上销售经验，3年以上管理经验
- 能力：销售管理、客户关系、团队领导
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 销售额达成 | 100%+ |
| 回款率 | ≥95% |
| 客户满意度 | ≥90% |
| 团队培养 | 晋升率≥20% |

### 2.2 销售经理

**向谁汇报**: 销售总监

**核心职责**:
1. 带领团队完成销售目标
2. 指导销售代表，提升团队能力
3. 管理重点客户关系
4. 协调售前技术支持

**具体工作任务**:
- 团队目标分解与跟踪 (每月)
- 销售代表辅导 (持续)
- 重点客户维护 (持续)
- 销售会议主持 (每周)

**协作关系**:
- 内部：销售组、市场组
- 外部：技术部(售前支持)、财务部(合同审批)、法务部(合同审核)

**任职要求**:
- 学历：本科及以上
- 经验：5年以上销售经验，2年以上管理经验
- 能力：销售技巧、客户管理、团队管理
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 团队销售额达成 | 100%+ |
| 销售周期 | 缩短15% |
| 客户满意度 | ≥90% |

### 2.3 销售代表 (各级)

**向谁汇报**: 销售经理

**核心职责**:
- P3 (高级): 负责大客户、复杂项目，指导初中级
- P2 (中级): 负责区域/行业客户，达成个人目标

**具体工作任务**:
- 客户开发与拜访 (持续)
- 需求调研与方案沟通 (持续)
- 报价与商务谈判 (持续)
- 合同签订与回款跟进 (持续)
- 与 SalesBrain 协作进行销售预测 (持续)

**协作关系**:
- 内部：销售组
- 外部：客户、售前技术支持、法务部

**任职要求**:
| 级别 | 学历 | 经验 | 能力 |
|------|------|------|------|
| P3 | 本科+ | 5年+ | 大客户销售、复杂谈判 |
| P2 | 大专+ | 2年+ | 客户开发、销售推进 |

**权限级别**:
- P3/P2: DEPARTMENT

**考核指标**:
| 指标 | 权重 |
|------|------|
| 销售额达成 | 50% |
| 回款率 | 20% |
| 客户开发数 | 15% |
| 客户满意度 | 15% |

### 2.4 市场经理

**向谁汇报**: 销售总监

**核心职责**:
1. 制定市场策略，提升品牌影响力
2. 统筹市场活动，扩大市场覆盖
3. 管理市场渠道，获取销售线索
4. 分析市场数据，优化市场投入

**具体工作任务**:
- 市场策略制定 (年度)
- 市场活动策划与执行 (按活动)
- 渠道合作管理 (持续)
- 市场数据分析 (每月)

**协作关系**:
- 内部：销售组、运营部(内容支持)
- 外部：合作伙伴、媒体渠道

**任职要求**:
- 学历：本科及以上，市场营销相关专业
- 经验：5年以上市场经验，2年以上管理经验
- 能力：市场策划、品牌管理、数据分析
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 线索获取量 | 达成率≥100% |
| 品牌曝光度 | 年度增长30% |
| 市场活动ROI | ≥3倍 |

### 2.5 市场专员

**向谁汇报**: 市场经理

**核心职责**:
1. 执行市场活动，收集反馈
2. 管理社交媒体运营
3. 协助销售团队获取线索
4. 市场资料制作与管理

**具体工作任务**:
- 市场活动执行 (按活动)
- 社交媒体运营 (持续)
- 销售物料管理 (持续)
- 市场数据收集 (持续)

**协作关系**:
- 内部：市场组
- 外部：合作伙伴、客户

**任职要求**:
- 学历：大专及以上，市场营销相关专业
- 经验：1年以上市场经验
- 能力：活动执行、社交媒体、沟通协调
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 活动执行率 | 100% |
| 线索转化率 | ≥10% |
| 内容发布准时率 | 100% |

## 3. 数字员工协作规范

### 3.1 销售部数字员工矩阵

| 数字员工 | 技能 | 协作场景 | 人类员工角色 |
|---------|------|---------|-------------|
| sales-predictor-001 | 销售预测 | 商机评估、成交概率预测 | 人工决策重点 |
| customer-insight-001 | 客户洞察 | 客户画像、需求分析 | 人工沟通验证 |
| proposal-generator-001 | 方案生成 | 销售方案、PPT生成 | 人工审核修改 |
| contract-reviewer-001 | 合同审查 | 合同条款风险识别 | 法务人工审核 |

### 3.2 人机协作流程

```
销售线索获取
    ↓
customer-insight-001 分析客户画像
    ↓
销售代表初步接触
    ↓
sales-predictor-001 评估商机，预测成交概率
    ↓
销售代表重点跟进高概率商机
    ↓
方案需求 → proposal-generator-001 生成初稿
    ↓
人工修改 → 客户沟通
    ↓
合同签订 → contract-reviewer-001 风险审查
    ↓
法务部审核 → 签约
```

## 4. 销售规范与流程

### 4.1 销售流程

```
线索获取 → 线索分配 → 客户开发 → 需求确认 → 方案沟通 → 商务谈判 → 合同签订 → 交付回款
```

### 4.2 销售分级

| 客户级别 | 定义 | 跟进策略 | 审批权限 |
|---------|------|---------|---------|
| A级 | 高意向+大客户 | 总监及以上重点跟进 | ≥50万需总经理审批 |
| B级 | 有需求+有预算 | 经理重点跟进 | ≥10万需经理审批 |
| C级 | 潜在客户 | 销售代表持续培育 | 销售代表自行跟进 |
