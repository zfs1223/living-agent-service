# 行政部岗位职责

**制度编号**: HR-14

**版本**: v1.0

**最后更新**: 2026-04-14

---

## 1. 部门概述

### 1.1 部门定位

行政部是公司行政后勤的核心支撑部门，负责行政事务、后勤保障、企业文化建设、办公设施管理，与 AdminBrain 深度协同，为公司提供高效行政支持。

### 1.2 部门使命

构建高效办公环境，塑造企业文化，保障公司正常运转。

### 1.3 组织架构

```
行政部
├── 行政总监 (M3)
│   ├── 行政专员 (P2)
│   └── 后勤保障组
│       ├── 后勤主管 (M1)
│       ├── 行政助理 (P1)
│       └── 保安/保洁 (若干)
```

## 2. 核心岗位职责

### 2.1 行政总监

**向谁汇报**: 总经理

**核心职责**:
1. 制定行政战略，规划行政资源
2. 统筹行政事务管理，确保高效运转
3. 推动企业文化建设，塑造组织氛围
4. 管理后勤保障，提升员工满意度

**具体工作任务**:
- 行政战略制定 (年度)
- 行政预算管理 (年度)
- 企业文化建设 (持续)
- 重大行政项目推进 (按项目)

**任职要求**:
- 学历：本科及以上，管理相关专业
- 经验：8年以上行政经验，3年以上管理经验
- 能力：行政管理、资源协调、文化建设
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 员工满意度 | ≥90% |
| 行政效率 | 满意度≥90% |
| 成本控制 | 预算内 |
| 安全事故 | 零重大事故 |

### 2.2 行政专员

**向谁汇报**: 行政总监

**核心职责**:
1. 统筹日常行政事务
2. 管理办公设施与设备
3. 组织行政采购与供应商管理
4. 协调行政服务与支持

**具体工作任务**:
- 日常行政事务处理 (每日)
- 办公设施管理 (持续)
- 行政采购执行 (按需)
- 供应商对接管理 (持续)
- 与 AdminBrain 协作进行智能行政 (持续)

**协作关系**:
- 内部：各部门
- 外部：供应商、外部服务商

**任职要求**:
- 学历：大专及以上，管理相关专业
- 经验：3年以上行政经验
- 能力：行政事务、沟通协调、成本意识
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 事务处理及时率 | ≥98% |
| 采购合规率 | 100% |
| 供应商满意度 | ≥90% |

### 2.3 后勤主管

**向谁汇报**: 行政总监

**核心职责**:
1. 管理后勤团队，保障后勤服务
2. 统筹安保与环境管理
3. 负责设施维护与维修
4. 应急事件协调处理

**具体工作任务**:
- 后勤团队管理 (持续)
- 安保与环境管理 (每日)
- 设施维护协调 (持续)
- 应急事件响应 (持续)

**协作关系**:
- 内部：各部门
- 外部：物业、安保公司、维修服务商

**任职要求**:
- 学历：大专及以上
- 经验：3年以上后勤管理经验
- 能力：后勤管理、安全管理、应急处理
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 后勤满意度 | ≥90% |
| 安保事件响应 | ≤5分钟 |
| 设施完好率 | ≥95% |

### 2.4 行政助理

**向谁汇报**: 行政专员/后勤主管

**核心职责**:
1. 前台接待与服务
2. 文件收发与档案管理
3. 办公用品管理与发放
4. 会议支持与后勤协助

**具体工作任务**:
- 前台来访接待 (每日)
- 文件收发与登记 (每日)
- 办公用品管理 (持续)
- 会议室支持 (持续)
- 后勤协助 (按需)

**协作关系**:
- 内部：行政部全员
- 外部：来访人员、快递/物流

**任职要求**:
- 学历：大专及以上
- 经验：1年以上行政经验
- 能力：服务意识、沟通表达、细致认真
- 权限：CHAT_ONLY (限制敏感权限)

**考核指标**:
| 指标 | 目标 |
|------|------|
| 接待满意度 | ≥95% |
| 事务准确率 | ≥99% |
| 工作及时率 | 100% |

### 2.5 保安/保洁

**向谁汇报**: 后勤主管

**核心职责**:
- 保安：安全巡逻、人员出入管理、应急响应
- 保洁：环境清洁、设施保养、垃圾处理

**具体工作任务**:
- 日常巡逻与安全检查 (每日)
- 出入管理与登记 (每日)
- 环境清洁与维护 (每日)
- 报修登记与跟踪 (持续)

**协作关系**:
- 内部：后勤主管
- 外部：物业、警方(应急)

**任职要求**:
- 学历：初中及以上
- 经验：保安需退伍军人/安保经验，保洁需相关经验
- 能力：责任心、安全意识
- 权限：CHAT_ONLY

**考核指标**:
| 岗位 | 指标 | 目标 |
|------|------|------|
| 保安 | 安全事件 | 零重大事件 |
| 保安 | 巡逻覆盖率 | 100% |
| 保洁 | 环境评分 | ≥4.5/5.0 |
| 保洁 | 清洁及时率 | 100% |

## 3. 数字员工协作规范

### 3.1 行政部数字员工矩阵

| 数字员工 | 技能 | 协作场景 | 人类员工角色 |
|---------|------|---------|-------------|
| admin-assistant-001 | 行政助理 | 来访预约、行程安排 | 人工接待 |
| procurement-001 | 采购管理 | 供应商对接、审批流程 | 人工决策 |
| facility-manager-001 | 设施管理 | 报修跟踪、设备监控 | 人工维护 |
| event-coordinator-001 | 活动协调 | 企业活动、团建策划 | 人工组织 |

### 3.2 人机协作流程

```
来访预约 → admin-assistant-001 智能接待安排
    ↓
行政助理确认 → 前台准备
    ↓
来访接待 (人工)
    ↓
报修需求 → facility-manager-001 记录跟踪
    ↓
后勤主管派单 → 维修处理
    ↓
活动需求 → event-coordinator-001 初步策划
    ↓
行政部审核 → 执行
```

## 4. 行政规范与流程

### 4.1 行政服务标准

| 服务类型 | 时效要求 | 责任岗位 |
|---------|---------|---------|
| 前台接待 | 即时 | 行政助理 |
| 快递收发 | 当日 | 行政助理 |
| 会议室预约 | 即时确认 | 行政助理 |
| 报修处理 | 简单当日/复杂3日 | 后勤组 |
| 访客接待 | 按预约 | 行政助理 |

### 4.2 采购流程

```
需求提交 → 行政专员审核 → 比价/询价 → 审批 → 采购 → 验收 → 入库/领用
```

### 4.3 费用审批

| 金额范围 | 审批人 |
|---------|--------|
| < 500元 | 行政专员 |
| 500-5000元 | 行政总监 |
| > 5000元 | 财务总监 |
