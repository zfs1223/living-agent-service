# 考勤与绩效管理制度

> **制度编号**：HR-02
> **制定部门**：人力资源部
> **版本**：v1.0
> **生效日期**：2026-04-14

---

## 1. 制度目的

本文档定义企业生命智能体中考勤管理与绩效考核的规范，确保人机协作环境下的工作管理与绩效评估有效运转。

## 2. 适用范围

- 所有在编人类员工
- 试用期员工（考勤适用，绩效另计）

**数字员工说明**：数字员工不适用考勤制度，其"在线状态"由系统根据任务执行情况自动管理。

## 3. 考勤管理

### 3.1 考勤方式

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           考勤方式定义                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【在线考勤】                                                            │
│  系统根据用户登录状态自动记录在线时长                                     │
│  └── 适用于：远程办公、弹性工时员工                                     │
│                                                                             │
│  【定时打卡】                                                            │
│  系统自动记录登录/登出时间                                              │
│  └── 适用于：坐班员工                                                   │
│                                                                             │
│  【项目工时】                                                            │
│  按项目任务记录工时                                                     │
│  └── 适用于：项目制员工                                                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.2 工时标准

| 岗位类型 | 标准工时 | 说明 |
|---------|---------|------|
| 全职员工 | 40小时/周 | 标准工时制 |
| 高级岗位 | 弹性工时 | 不强制打卡，以成果为准 |
| 项目制 | 按项目约定 | 以工时记录为准 |
| 实习生 | 32小时/周 | 兼职标准 |

### 3.3 考勤异常处理

| 异常类型 | 处理方式 | 说明 |
|---------|---------|------|
| 迟到 | 记录并扣除相应绩效分 | 30分钟内不扣分 |
| 早退 | 记录并扣除相应绩效分 | 30分钟内不扣分 |
| 旷工 | 全天无考勤记录 | 扣除当日全部工资 |
| 请假 | 通过系统提交申请 | 审批后生效 |

### 3.4 请假类型

| 类型 | 天数上限 | 说明 | AccessLevel要求 |
|------|---------|------|----------------|
| 年假 | 按司龄计算 | 员工福利 | 无特殊要求 |
| 病假 | 30天/年 | 需要证明 | 无特殊要求 |
| 事假 | 10天/年 | 无证明要求 | 无特殊要求 |
| 婚假 | 法定标准 | 结婚证明 | 无特殊要求 |
| 产假/陪产假 | 法定标准 | 证明材料 | 无特殊要求 |
| 培训假 | 按需 | 培训批准 | 无特殊要求 |

### 3.5 考勤与AccessLevel联动

根据核心框架 `06-security-permission.md`，考勤状态与系统权限无直接联动，但会影响：
- 绩效评分
- 晋升评估
- 数字员工任务分配

## 4. 绩效管理

### 4.1 绩效评估周期

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           绩效评估周期                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【月度评估】                                                            │
│  适用于：所有员工                                                       │
│  评估内容：任务完成率、工作质量、协作表现                                 │
│                                                                             │
│  【季度评估】                                                            │
│  适用于：全体员工                                                       │
│  评估内容：目标达成、成长进步、贡献度                                   │
│                                                                             │
│  【年度评估】                                                            │
│  适用于：全体员工                                                       │
│  评估内容：年度目标达成、晋升评估、薪酬调整                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 绩效维度

| 维度 | 权重 | 说明 | 评估来源 |
|------|------|------|---------|
| 任务完成 | 30% | 工作任务完成率 | 系统自动统计 |
| 工作质量 | 25% | 输出成果质量 | 主管评估 |
| 协作贡献 | 20% | 人机协作效率 | 系统+主管 |
| 能力成长 | 15% | 技能提升、学习表现 | 系统记录 |
| 创新贡献 | 10% | 改进建议、创新成果 | 评审委员会 |

### 4.3 绩效等级

| 等级 | 分值范围 | 说明 | 奖励 |
|------|---------|------|------|
| A | 90-100 | 卓越 | 晋升优先+奖金 |
| B | 80-89 | 优秀 | 奖金 |
| C | 70-79 | 良好 | 正常薪资 |
| D | 60-69 | 待改进 | 改进计划 |
| E | <60 | 不达标 | 降级或离职 |

### 4.4 人机协作绩效

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       人机协作绩效评估                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【评估指标】                                                            │
│  ├── 数字员工调度效率 - 任务分配合理性                                   │
│  ├── 协作完成率 - 人机协作任务的完成情况                                 │
│  ├── 知识贡献 - 沉淀到L2/L3的知识条目数                                  │
│  └── 问题解决率 - 借助数字员工解决的问题比例                              │
│                                                                             │
│  【评估原则】                                                            │
│  ├── 数字员工是助手，不是替代者                                         │
│  ├── 员工因善用数字员工而获得更高评价                                   │
│  └── 纯人工完成的简单任务不优于人机协作完成的高质量任务                  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.5 绩效评估流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           绩效评估流程                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【月度自评】                                                            │
│  员工 → 填写月度工作总结 → 提交系统                                     │
│                                                                             │
│  【主管评价】                                                            │
│  直属主管 → 查看员工数据 → 给出评价 → 提交HR                           │
│                                                                             │
│  【系统统计】                                                            │
│  系统 → 汇总任务完成数据 → 计算协作评分 → 提交评估报告                   │
│                                                                             │
│  【绩效面谈】                                                            │
│  主管与员工 → 反馈绩效结果 → 制定改进计划                               │
│                                                                             │
│  【结果归档】                                                            │
│  HR → 归档绩效记录 → 更新员工档案                                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. 晋升管理

### 5.1 晋升通道

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           晋升通道定义                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【管理序列】                                                            │
│  M1 → M2 → M3 → M4 → M5                                               │
│  适用于：有管理潜力的员工                                                │
│                                                                             │
│  【专业序列】                                                            │
│  P1 → P2 → P3 → P4 → P5                                               │
│  适用于：深耕专业领域的员工                                              │
│                                                                             │
│  【横向发展】                                                            │
│  不同部门/岗位间转换                                                    │
│  适用于：寻求多元化发展的员工                                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 晋升条件

| 晋升层级 | 必要条件 | 参考条件 |
|---------|---------|---------|
| M1→M2 | 连续2年绩效B+以上 | 有下属管理经验 |
| M2→M3 | 连续2年绩效A以上 | 跨部门协作经验 |
| P1→P2 | 连续2年绩效B+以上 | 主导过重要项目 |
| P2→P3 | 绩效A以上 | 具备领域专家能力 |

### 5.3 晋升评估要素

| 要素 | 说明 | 权重 |
|------|------|------|
| 绩效结果 | 近2年绩效评分 | 40% |
| 能力评估 | 专业能力与管理能力 | 25% |
| 潜力评估 | 学习成长速度 | 20% |
| 协作评估 | 人机协作效率 | 15% |

## 6. 薪酬管理

### 6.1 薪酬结构

| 组成 | 说明 | 发放周期 |
|------|------|---------|
| 基本工资 | 岗位对应的基准工资 | 月 |
| 绩效工资 | 与绩效等级挂钩 | 月/季 |
| 年终奖金 | 与年度绩效挂钩 | 年 |
| 福利补贴 | 餐补、交通补、通讯补等 | 月 |

### 6.2 薪酬调整

| 调整类型 | 时机 | 依据 |
|---------|------|------|
| 年度调薪 | 每年1月 | 年度绩效结果 |
| 晋升调薪 | 晋升生效时 | 新岗位薪酬标准 |
| 市场调薪 | 按市场行情 | HR定期调研 |
| 特殊调薪 | 按需 | 审批后执行 |

## 7. 奖惩管理

### 7.1 奖励类型

| 类型 | 说明 | 奖励形式 |
|------|------|---------|
| 绩效奖 | 优秀绩效 | 奖金 |
| 项目奖 | 重大项目贡献 | 奖金 |
| 创新奖 | 创新建议采纳 | 奖金+荣誉 |
| 协作奖 | 人机协作典范 | 荣誉+奖励 |

### 7.2 惩戒类型

| 类型 | 说明 | 处理方式 |
|------|------|---------|
| 轻微违规 | 迟到早退等 | 警告+扣分 |
| 一般违规 | 未完成工作任务 | 绩效降级 |
| 严重违规 | 泄露信息、违规操作 | 降级/解除 |
| 违法违纪 | 违法行为 | 解除+法律处理 |

## 8. 数字员工协作积分

### 8.1 协作积分定义

为鼓励员工高效使用数字员工，引入协作积分制度：

| 行为 | 积分 | 说明 |
|------|------|------|
| 发起有效任务 | +1 | 任务被数字员工接受并完成 |
| 知识沉淀贡献 | +2 | 有效知识条目被采纳 |
| 数字员工调度优化 | +3 | 提出的调度建议被采纳 |
| 培训新员工使用数字员工 | +5 | 成功教会他人 |

### 8.2 积分用途

| 用途 | 所需积分 | 说明 |
|------|---------|------|
| 兑换培训机会 | 50 | 优先参加外部培训 |
| 兑换荣誉 | 30 | "人机协作达人"称号 |
| 绩效加分 | 20/+1分 | 绩效评估加分 |
