# 人力资源部岗位职责

**制度编号**: HR-10

**版本**: v1.0

**最后更新**: 2026-04-14

---

## 1. 部门概述

### 1.1 部门定位

人力资源部是公司人才管理的核心部门，负责人才战略规划、招聘配置、培训发展、绩效薪酬、员工关系，与 HrBrain 深度协同，实现人力资源数字化管理。

### 1.2 部门使命

构建高效人才供应链，打造学习型组织，支撑公司战略实现。

### 1.3 组织架构

```
人力资源部
├── 人力总监 (M3)
│   ├── 招聘组
│   │   ├── 招聘经理 (M1)
│   │   ├── 高级招聘专员 (P3)
│   │   └── 招聘专员 (P2)
│   ├── 培训组
│   │   ├── 培训经理 (M1)
│   │   └── 培训专员 (P2)
│   └── 薪酬绩效组
│       ├── 薪酬绩效经理 (M1)
│       └── 薪酬绩效专员 (P2)
```

---

## 2. 核心岗位职责

### 2.1 人力总监

**向谁汇报**: 总经理

**核心职责**:
1. 制定人力资源战略，对齐公司业务战略
2. 统筹人才管理体系建设，推动组织发展
3. 管理核心人才，降低人才流失风险
4. 推动人效提升，优化人力成本

**具体工作任务**:
- 人力资源战略制定 (年度)
- 核心人才发展规划 (持续)
- 重大组织调整决策 (按需)
- 管理层人力资源汇报 (季度)

**任职要求**:
- 学历：本科及以上，人力资源/管理相关专业
- 经验：10年以上HR经验，5年以上管理经验
- 能力：战略规划、人才洞察、组织变革
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 人才满意度 | ≥90% |
| 核心人才流失率 | ≤5% |
| 招聘及时率 | ≥90% |
| 人效提升 | 年度提升10% |

### 2.2 招聘经理

**向谁汇报**: 人力总监

**核心职责**:
1. 制定招聘策略，优化招聘流程
2. 统筹招聘项目执行，完成招聘目标
3. 管理招聘渠道，建立人才库
4. 与 HrBrain 协作，优化智能招聘

**具体工作任务**:
- 年度招聘计划编制 (年度)
- 招聘渠道管理 (持续)
- 关键岗位招聘执行 (按需)
- 招聘数据分析与改进 (每月)

**协作关系**:
- 内部：培训组、薪酬绩效组
- 外部：各部门(需求对接)、猎头/校招合作方

**任职要求**:
- 学历：本科及以上，人力资源/管理相关专业
- 经验：6年以上招聘经验，2年以上管理经验
- 能力：人才识别、渠道运营、数据分析
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 招聘完成率 | ≥95% |
| 招聘周期 | ≤30天(社招)、≤15天(校招) |
| 招聘满意度 | ≥90% |

### 2.3 招聘专员 (各级)

**向谁汇报**: 招聘经理

**核心职责**:
- P3 (高级): 关键/稀缺岗位招聘、猎头管理、指导初级
- P2 (中级): 常规岗位招聘、校园招聘、执行运营

**具体工作任务**:
- 岗位需求沟通与分析 (持续)
- 简历筛选与面试安排 (持续)
- 面试组织与候选人跟进 (持续)
- 招聘数据统计与报表 (每周)

**协作关系**:
- 内部：招聘组
- 外部：用人部门、候选人

**任职要求**:
- 学历：本科及以上
- 经验：P3需4年+，P2需2年+
- 能力：沟通表达、人才识别、细节把控
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 权重 |
|------|------|
| 招聘完成率 | 40% |
| 招聘周期 | 30% |
| 候选人体验 | 20% |
| 数据质量 | 10% |

### 2.4 培训经理

**向谁汇报**: 人力总监

**核心职责**:
1. 搭建培训体系，制定培训规划
2. 统筹培训项目实施，评估培训效果
3. 管理内部讲师队伍
4. 推动学习型组织建设

**具体工作任务**:
- 年度培训计划制定 (年度)
- 培训体系优化 (持续)
- 重点培训项目执行 (按项目)
- 培训效果评估与改进 (持续)

**协作关系**:
- 内部：招聘组、薪酬绩效组
- 外部：外部培训机构、各部门

**任职要求**:
- 学历：本科及以上，人力资源/教育相关专业
- 经验：5年以上培训经验，2年以上管理经验
- 能力：培训体系、课程开发、效果评估
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 培训计划完成率 | ≥95% |
| 培训满意度 | ≥4.0/5.0 |
| 培训覆盖率 | ≥90% |

### 2.5 培训专员

**向谁汇报**: 培训经理

**核心职责**:
1. 辅助培训计划执行
2. 培训资源对接与管理
3. 培训数据统计与档案管理

**具体工作任务**:
- 培训项目执行支持 (按项目)
- 培训资源协调 (持续)
- 培训档案管理 (持续)
- 培训数据分析 (每月)

**协作关系**:
- 内部：培训组
- 外部：外部讲师、培训机构

**任职要求**:
- 学历：本科及以上
- 经验：2年以上培训相关经验
- 能力：项目协调、沟通表达、细致认真
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 培训执行率 | 100% |
| 档案完整率 | 100% |
| 满意度评分 | ≥4.0 |

### 2.6 薪酬绩效经理

**向谁汇报**: 人力总监

**核心职责**:
1. 设计薪酬体系，确保竞争力与公平性
2. 搭建绩效管理体系，推动绩效落地
3. 管理薪酬核算，确保准确及时
4. 与 HrBrain 协作，优化智能薪酬绩效

**具体工作任务**:
- 薪酬体系设计与优化 (年度)
- 绩效考核方案制定 (年度)
- 月度薪酬核算与发放 (每月)
- 薪酬数据分析与报告 (每月)

**协作关系**:
- 内部：招聘组、培训组
- 外部：财务部(薪酬发放)、各部门(绩效对接)

**任职要求**:
- 学历：本科及以上，人力资源/财务相关专业
- 经验：5年以上薪酬绩效经验，2年以上管理经验
- 能力：薪酬设计、绩效管理、数据分析
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 薪酬发放准确率 | 100% |
| 绩效完成率 | 100% |
| 薪酬竞争力 | P50以上 |

### 2.7 薪酬绩效专员

**向谁汇报**: 薪酬绩效经理

**核心职责**:
1. 辅助薪酬核算与发放
2. 绩效数据收集与汇总
3. 社保公积金管理
4. 人事档案管理

**具体工作任务**:
- 每月考勤与薪酬核算 (每月)
- 社保公积金办理 (每月)
- 绩效数据汇总 (每季度)
- 人事档案整理归档 (持续)

**协作关系**:
- 内部：薪酬绩效组
- 外部：财务部、社保局

**任职要求**:
- 学历：本科及以上，人力资源/财务相关专业
- 经验：2年以上薪酬绩效经验
- 能力：数据处理、细致认真、原则性
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 核算准确率 | 100% |
| 发放及时率 | 100% |
| 档案完整率 | 100% |

## 3. 数字员工协作规范

### 3.1 人力资源部数字员工矩阵

| 数字员工 | 技能 | 协作场景 | 人类员工角色 |
|---------|------|---------|-------------|
| recruiter-001 | 智能招聘 | 简历筛选、面试安排 | 人工面试决策 |
| performance-analyst-001 | 绩效分析 | 绩效数据汇总、对比分析 | 人工反馈沟通 |
| onboarding-001 | 入职引导 | 新员工入职流程自动化 | 人工关怀 |
| compliance-checker-001 | 合规检查 | 劳动合同、考勤合规 | 人工审批 |

### 3.2 人机协作流程

```
招聘需求提交
    ↓
recruiter-001 简历筛选与匹配
    ↓
招聘专员人工筛选 → 面试安排
    ↓
面试评估 (人类决策)
    ↓
onboarding-001 发起入职流程
    ↓
培训组安排入职培训
    ↓
薪酬绩效组核算 → 发放
    ↓
performance-analyst-001 绩效数据汇总
    ↓
人工绩效反馈沟通
```

## 4. 人事规范与流程

### 4.1 入职流程

```
offer确认 → 背景调查 → 入职准备 → 入职当天 → 试用期 → 转正
```

### 4.2 权限配置流程

依据《03-统一员工模型》§3.2：

| 阶段 | 权限级别 | 开通内容 |
|------|---------|---------|
| 入职前 | CHAT_ONLY | 接收入职通知 |
| 入职当天 | LIMITED | 基础办公系统 |
| 试用期 | LIMITED | 受限功能 |
| 转正后 | DEPARTMENT | 完整权限 |
