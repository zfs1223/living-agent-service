# 财务部岗位职责

**制度编号**: HR-09

**版本**: v1.0

**最后更新**: 2026-04-14

---

## 1. 部门概述

### 1.1 部门定位

财务部是公司财务管理的核心部门，负责财务核算、预算管理、资金管理、风险控制，与 FinanceBrain 协同，实现财务数字化管理。

### 1.2 部门使命

保障公司财务健康，合规经营，为管理层提供准确、及时的财务决策支持。

### 1.3 组织架构

```
财务部
├── 财务总监 (M3)
│   ├── 会计组
│   │   ├── 会计经理 (M1)
│   │   ├── 高级会计 (P3)
│   │   ├── 会计 (P2)
│   │   └── 出纳 (P1)
│   └── 预算组
│       ├── 预算经理 (M1)
│       └── 预算专员 (P2)
```

## 2. 核心岗位职责

### 2.1 财务总监

**向谁汇报**: 总经理

**核心职责**:
1. 制定财务战略规划，保障公司财务健康
2. 统筹财务核算与报告，确保合规准确
3. 管理资金运作，优化资金效率
4. 推动财务数字化，与 FinanceBrain 深度协同

**具体工作任务**:
- 财务战略制定 (年度)
- 重大财务决策参与 (按需)
- 向董事会汇报财务状况 (季度)
- 资金统筹与风险管理 (持续)

**任职要求**:
- 学历：本科及以上，财务/会计相关专业
- 资格：注册会计师(CPA)优先
- 经验：10年以上财务经验，5年以上管理经验
- 能力：财务分析、风险管控、团队管理
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 财务报告及时性 | 按时完成率100% |
| 资金使用效率 | 闲置资金≤5% |
| 合规性 | 零重大违规 |
| 成本控制 | 费用预算执行率98-102% |

### 2.2 会计经理

**向谁汇报**: 财务总监

**核心职责**:
1. 统筹日常会计核算，确保账务准确
2. 管理财务报表编制，按时出具报告
3. 监督税务申报，防范税务风险
4. 维护财务系统，与 FinanceBrain 数据对接

**具体工作任务**:
- 月度结账与报表编制 (每月)
- 税务申报与缴纳 (每月)
- 财务系统维护 (持续)
- 会计档案管理 (持续)

**协作关系**:
- 内部：预算组
- 外部：税务局、审计机构

**任职要求**:
- 学历：本科及以上，财务/会计相关专业
- 资格：中级会计师及以上
- 经验：6年以上会计经验，2年以上管理经验
- 能力：会计核算、报表编制、税务筹划
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 结账及时性 | 5个工作日内完成 |
| 报表准确率 | 100% |
| 税务合规率 | 100% |

### 2.3 会计 (各级)

**向谁汇报**: 会计经理

**核心职责**:
- P3 (高级): 复杂业务处理、税务筹划、指导初级
- P2 (中级): 日常核算、报表编制、档案管理
- P1 (初级): 辅助核算、发票管理

**具体工作任务**:
- 原始凭证审核与记账
- 各类账务处理 (持续)
- 发票管理与税务申报辅助 (持续)
- 会计档案整理归档 (持续)
- 与 FinanceBrain 协作进行自动核算 (持续)

**协作关系**:
- 内部：会计组内协作
- 外部：业务部门(费用报销)、税务局

**任职要求**:
| 级别 | 学历 | 资格 | 经验 |
|------|------|------|------|
| P3 | 本科+ | 中级会计师+ | 5年+ |
| P2 | 本科 | 初级会计师+ | 2年+ |
| P1 | 大专+ | 会计从业资格证 | 应届/1年 |

**权限级别**:
- P3/P2: DEPARTMENT
- P1: LIMITED (限制敏感权限)

**考核指标**:
| 指标 | 权重 |
|------|------|
| 账务准确率 | 40% |
| 报表按时完成率 | 30% |
| 工作效率 | 20% |
| 档案规范性 | 10% |

### 2.4 出纳

**向谁汇报**: 会计经理

**核心职责**:
1. 办理日常现金收支业务
2. 管理银行账户，确保资金安全
3. 核对银行流水，编制资金报表
4. 管理发票和收据

**具体工作任务**:
- 现金收付操作 (每日)
- 银行转账与对账 (每日)
- 资金日报编制 (每日)
- 发票收据管理 (持续)

**协作关系**:
- 内部：会计组
- 外部：银行

**任职要求**:
- 学历：大专及以上，财务相关专业
- 经验：1年以上出纳经验
- 能力：细心认真、原则性强
- 权限：CHAT_ONLY (限制资金操作权限)

**考核指标**:
| 指标 | 目标 |
|------|------|
| 资金准确性 | 100% |
| 操作合规率 | 100% |
| 报告及时性 | 100% |

### 2.5 预算经理

**向谁汇报**: 财务总监

**核心职责**:
1. 统筹年度预算编制，控制预算执行
2. 定期预算分析，预警超支风险
3. 优化预算流程，提升预算效率
4. 参与经营分析，支持决策

**具体工作任务**:
- 年度预算编制 (年度)
- 季度预算调整 (季度)
- 月度预算执行分析 (每月)
- 预算系统优化 (持续)

**协作关系**:
- 内部：会计组
- 外部：各部门(预算对接)

**任职要求**:
- 学历：本科及以上，财务/会计相关专业
- 经验：5年以上财务经验，2年以上预算管理经验
- 能力：预算编制、数据分析、沟通协调
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 预算编制质量 | 偏差≤5% |
| 预算执行偏差 | ≤10% |
| 预算分析及时性 | 5个工作日内 |

### 2.6 预算专员

**向谁汇报**: 预算经理

**核心职责**:
1. 辅助预算编制，收集预算数据
2. 跟踪预算执行，编制执行报告
3. 维护预算系统数据
4. 汇总各部门预算需求

**具体工作任务**:
- 预算数据收集与汇总 (按周期)
- 预算执行跟踪 (每月)
- 预算报表编制 (每月)
- 系统数据维护 (持续)

**协作关系**:
- 内部：预算组
- 外部：各部门预算对接人

**任职要求**:
- 学历：本科及以上，财务相关专业
- 经验：2年以上工作经验
- 能力：Excel/数据分析、沟通协调
- 权限：DEPARTMENT

**考核指标**:
| 指标 | 目标 |
|------|------|
| 数据收集完整率 | 100% |
| 报表准确率 | ≥99% |
| 工作时效性 | 100% |

## 3. 数字员工协作规范

### 3.1 财务部数字员工矩阵

| 数字员工 | 技能 | 协作场景 | 人类员工角色 |
|---------|------|---------|-------------|
| accountant-001 | 智能核算 | 发票识别、自动记账 | 人工复核确认 |
| budget-analyst-001 | 预算分析 | 预算执行分析、预警 | 人工决策 |
| report-generator-001 | 报表生成 | 财务报表自动生成 | 人工审核 |
| compliance-checker-001 | 合规检查 | 费用合规性审查 | 人工审批 |

### 3.2 人机协作流程

```
业务发生
    ↓
原始凭证提交
    ↓
accountant-001 智能识别与记账
    ↓
会计人工复核与调整
    ↓
budget-analyst-001 执行预算检查
    ↓
预算经理审批
    ↓
report-generator-001 生成财务报表
    ↓
财务总监审核 → 管理层汇报
```

## 4. 财务规范与流程

### 4.1 报销流程

```
员工提单 → 部门负责人审批 → 财务审核 → 预算检查 → 出纳付款 → 归档
```

### 4.2 财务审批权限

| 金额范围 | 审批人 |
|---------|--------|
| < 1000元 | 部门负责人 |
| 1000-10000元 | 财务经理 |
| 10000-50000元 | 财务总监 |
| > 50000元 | 总经理/董事会 |
