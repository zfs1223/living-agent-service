# Naming Conventions

## Markdown documents

Preferred format:

```text
<department>-<sequence>-<topic>.md
```

Examples:

- `hr-01-employee-lifecycle.md`
- `finance-02-reimbursement-policy.md`
- `tech-03-deployment-runbook.md`
- `sales-04-customer-proposal-template.md`

## Directories

- Use lowercase English names
- Use hyphens for multi-word folder names
- Keep folder names stable once published

## Versioning

If a document must keep historical versions, prefer:

- `filename.v1.md`
- `filename.v2.md`

or move old versions to `archive/`
