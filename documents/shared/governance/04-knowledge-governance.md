# 知识分层治理

> 对齐项目核心框架 `04-knowledge-system.md`，定义企业生命智能体中知识子系统的治理规范。

## 1. 知识分层模型

根据 `04-knowledge-system.md` §1：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           知识分层模型                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【L1 私有知识】                                                           │
│  与员工/会话绑定，强调隐私与低延迟                                          │
│                                                                             │
│  【L2 部门知识】                                                           │
│  部门共享，承载最佳实践与业务规则                                           │
│                                                                             │
│  【L3 全局知识】                                                           │
│  全公司共享，承载通用制度与跨部门经验                                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 知识条目框架

根据 `04-knowledge-system.md` §2：

```
KnowledgeEntry（知识条目最小单元）
├── 内容（Content）
├── 元数据（Metadata）
│   ├── type - 类型
│   ├── domain - 领域
│   ├── tags - 标签
│   ├── validity - 有效性
│   ├── importance - 重要性
│   └── confidence - 置信度
├── 作用域（Scope）
└── 评分（Rating）
```

## 3. 生命周期

根据 `04-knowledge-system.md` §2：

```
创建 → 使用 → 评估 → 晋升/衰退 → 归档
```

| 阶段 | 说明 |
|------|------|
| 创建 | 新增知识条目，标注初始作用域和评分 |
| 使用 | 被检索和引用，累计使用统计 |
| 评估 | 根据使用情况和反馈进行质量评估 |
| 晋升 | 高质量知识从L2晋升L3 |
| 衰退 | 低质量或过时知识降级或归档 |
| 归档 | 不再使用的知识转入归档状态 |

### 4.1 权限判定矩阵

| 知识层级 | 创建权限 | 读取权限 | 晋升权限 |
|---------|---------|---------|---------|
| L1私有 | 仅所有者 | 所有者 | N/A |
| L2部门 | 部门成员 | 部门成员 | 部门负责人 |
| L3全局 | 授权人员 | 全员 | 审批委员会 |

## 6. 知识进化规则

根据 `04-knowledge-system.md` §5：

### 6.1 晋升规则

```
达到使用阈值 + 质量评分 + 多角色引用 → 晋升
```

| 条件 | 说明 |
|------|------|
| 使用阈值 | 被引用次数达到设定值 |
| 质量评分 | 综合评分超过晋升线 |
| 多角色引用 | 被多个不同角色引用 |

### 6.2 衰退规则

```
长期未使用 OR 与新知识冲突 → 衰退
```

### 6.3 替换规则

```
新知识通过版本标记替代旧条目
```
