## 2. 核心运行链路

根据 `02-core-architecture.md` §2：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           核心运行链路                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. Gateway接收请求（HTTP/WebSocket）                                      │
│                      │                                                      │
│                      ▼                                                      │
│  2. 安全层完成身份识别与访问级别判定                                        │
│                      │                                                      │
│                      ▼                                                      │
│  3. 路由层按意图和权限选择目标大脑（Main/Dept/Chat/Tool）                  │
│                      │                                                      │
│                      ▼                                                      │
│  4. 大脑通过BrainContext组装模型、知识、技能、指令                          │
│                      │                                                      │
│                      ▼                                                      │
│  5. 进入ReAct循环：推理 → 工具调用 → 结果回写                            │
│                      │                                                      │
│                      ▼                                                      │
│  6. 将响应写入通道并返回客户端                                              │
│                      │                                                      │
│                      ▼                                                      │
│  7. 并行沉淀：使用统计、知识条目、进化信号、审计日志                        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3. BrainContext结构

```

```

## 4. 部门大脑职责

### 4.1 大脑类型与核心能力

根据 `02-core-architecture.md` §3.1：

| 大脑 | 职责 | 核心能力 |
|------|------|---------|
| MainBrain | 跨部门协调 | 复杂任务分解、战略协调 |
| TechBrain | 技术研发 | 代码审查、CI/CD、架构设计 |
| HrBrain | 人力资源 | 招聘、培训、绩效 |
| FinanceBrain | 财务管理 | 预算、报销、报表 |
| OpsBrain | 运营管理 | 数据分析、运营策略 |
| SalesBrain | 销售管理 | 客户管理、市场分析 |
| CsBrain | 客服 | 工单处理、问题解答 |
| AdminBrain | 行政管理 | 行政事务、资源管理 |
| LegalBrain | 法务 | 合同审查、合规检查 |

### 4.2 大脑调度规则

```
人类输入 → 权限检查 → 路由层 → MainBrain（跨部门）
                            └──→ 部门Brain（领域任务）
```

## 5. 结构约束

根据 `02-core-architecture.md` §4：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           核心结构约束                                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【约束1】Brain不直接依赖外部系统SDK                                       │
│           统一通过Tool/Skill适配                                            │
│                                                                             │
│  【约束2】权限检查必须先于路由执行                                          │
│                                                                             │
│  【约束3】知识写入必须标注作用域（L1/L2/L3）                               │
│                                                                             │
│  【约束4】进化执行必须可追踪、可熔断、可回滚（策略层面）                     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 8. 与其他域的协作

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           大脑与其他域协作                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【与Employee域】                                                          │
│  Brain根据department/role/capabilities路由                                 │
│                                                                             │
│  【与Knowledge域】                                                          │
│  Brain通过DynamicPromptBuilder注入知识片段                                 │
│  RAG检索结果只读，禁止直接写回系统提示                                       │
│                                                                             │
│  【与Evolution域】                                                         │
│  Brain执行产生进化信号                                                      │
│  进化策略执行结果回写到Brain能力配置                                        │
│                                                                             │
│  【与Security域】                                                          │
│  Brain访问前必须通过BrainAccessControl校验                                  │
│                                                                             │
│  【与Channel域】                                                           │
│  Brain处理结果写入ChannelManager                                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
