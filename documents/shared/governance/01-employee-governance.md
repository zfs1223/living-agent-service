# 统一员工治理

> 对齐项目核心框架 `03-employee-model.md`，定义企业生命智能体中统一员工模型的治理规范。

## 1. 模型目标

根据 `03-employee-model.md` §1：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           统一员工模型目标                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  统一身份语义：不区分调用入口，统一以Employee参与系统协作                      │
│                                                                             │
│  统一权限语义：访问级别与身份态可直接驱动路由和资源访问                      │
│                                                                             │
│  统一协作语义：均可通过Channel参与任务流转                                    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 核心抽象

根据 `03-employee-model.md` §2：

```
Employee（统一接口）
├── 暴露：身份、组织、能力、状态、配置
├──
├── HumanEmployee（企业账号映射实体）
│   └── 强调：外部身份同步
│
└── DigitalEmployee（系统内生实体）
    └── 强调：自治配置与运行态
```

## 3. 关键字段分层

根据 `03-employee-model.md` §3：

| 层级 | 字段 | 说明 |
|------|------|------|
| 身份层 | `employeeId`、`employeeType`、`authId/provider` | 唯一标识与认证信息 |
| 组织层 | `department`、`roles`、`managerId` | 归属与汇报关系 |
| 能力层 | `capabilities`、`skills`、`tools` | 技能与工具授权 |
| 治理层 | `accessLevel`、`identity`、`status` | 权限与状态 |
| 个性层 | `EmployeePersonality` | 个性特征 |
| 差异层 | `HumanConfig` / `DigitalConfig` | 分类配置 |

## 7. 与其他域的契约

根据 `03-employee-model.md` §7：

| 域 | 契约 | 说明 |
|----|------|------|
| Security | `AuthContext + AccessLevel` | 驱动可访问资源 |
| Brain | `department/role/capabilities` | 驱动路由 |
| Knowledge | 身份与作用域 | 决定读写权限 |
| Evolution | 数字员工触发进化策略 | 回写能力变更 |

## 9. 启动期一致性校验

根据 `03-employee-model.md` §9.3：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         启动期校验规则                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【校验内容】                                                              │
│  系统启动时校验固定员工工具配置是否：                                       │
│  ├── 可映射到已注册工具                                                    │
│  └── 落在部门白名单或共享工具集合内                                          │
│                                                                             │
│  【严格模式】                                                              │
│  配置项：living-agent.fixed-employee.tools.strict                           │
│  ├── false（默认）：记录告警，不阻断启动                                    │
│  └── true：发现违规配置即启动失败（fail-fast）                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 10. 现状缺失与治理建议

根据 `03-employee-model.md` §11：

| 缺失项 | 治理建议 |
