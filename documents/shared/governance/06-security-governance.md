# 安全权限治理

> 对齐项目核心框架 `06-security-permission.md`，定义企业生命智能体中安全与权限子系统的治理规范。

## 1. 核心原则

根据 `06-security-permission.md` §1：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           核心安全原则                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. 先认证再授权，先授权再路由                                            │
│                                                                             │
│  2. 默认最小权限（Least Privilege）                                       │
│                                                                             │
│  3. 高风险动作默认拒绝，必要时人工审批                                    │
│                                                                             │
│  4. 全链路可审计、可追溯、可复盘                                           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3. 授权框架

根据 `06-security-permission.md` §3：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           访问级别体系                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【CHAT_ONLY】                                                          │
│  仅闲聊（Qwen3-0.6B）                                                    │
│  适用：离职员工、外部访客                                                  │
│                                                                             │
│  【LIMITED】                                                              │
│  部分大脑访问                                                             │
│  适用：试用期员工、客户、合作伙伴                                          │
│                                                                             │
│  【DEPARTMENT】                                                           │
│  本部门完整功能                                                          │
│  适用：在职员工                                                           │
│                                                                             │
│  【FULL】                                                                 │
│  所有资源                                                                │
│  适用：董事长、高管                                                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.1 判定维度

```
身份（UserIdentity）+ 访问级别（AccessLevel）+ 部门（Department）+ 资源类型
```

### 3.2 授权执行点

```
API入口 → WebSocket入口 → Brain路由前 → 工具调用前
```

## 7. 审计层级

| 审计级别 | 场景 | 保存周期 |
|---------|------|---------|
| 轻审计 | 登录、普通操作 | 1年 |
| 中审计 | 权限变更、敏感访问 | 5年 |
| 强审计 | 高风险命令、组织变更 | 10年+ |
