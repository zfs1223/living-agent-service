## 2. 环境分层

根据 `07-deployment-operations.md` §2：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           环境分层定义                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【开发环境 Dev】                                                        │
│  快速验证，配置宽松                                                     │
│                                                                             │
│  【测试环境 Test/Staging】                                               │
│  联调验证，近生产配置                                                   │
│                                                                             │
│  【生产环境 Prod】                                                       │
│  高可用、审计开启、严格权限策略                                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.1 环境差异策略

| 配置项 | Dev | Test | Prod |
|-------|-----|------|------|
| 审计 | 可选 | 开启 | 开启 |
| 权限 | 宽松 | 中等 | 严格 |
| 日志级别 | DEBUG | INFO | WARN |
| 性能 | 低配 | 中配 | 高配 |
