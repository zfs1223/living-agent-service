# 对外合作与签约制度

**制度编号**: HR-18

**版本**: v1.0

**最后更新**: 2026-04-14

---

## 1. 目的与范围

### 1.1 目的

本制度规范一人公司对外合作的流程、签约管理、合作伙伴关系，确保公司利益不受损害，合作过程合规高效。

### 1.2 适用范围

- 外部服务商合作
- 客户项目合作
- 技术合作伙伴
- 渠道合作伙伴
- 其他商业合作

### 1.3 一人公司特殊考虑

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         一人公司对外合作特点                                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【挑战】                                                                  │
│  ├── 无专业法务团队                                                        │
│  ├── 创始人精力有限                                                        │
│  ├── 风险承担能力弱                                                        │
│  └── 决策集中度高                                                          │
│                                                                             │
│  【机遇】                                                                  │
│  ├── 决策灵活                                                              │
│  ├── 数字员工可处理大量协作事务                                            │
│  ├── 快速响应市场                                                          │
│  └── 成本可控                                                              │
│                                                                             │
│  【关键控制点】                                                            │
│  ├── 创始人保留最终审批权                                                  │
│  ├── 法务部数字员工(LegalBrain)辅助审查                                    │
│  ├── 财务部数字员工(FinanceBrain)辅助评估                                 │
│  └── 知识库记录全流程                                                      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 合作分类与权限

### 2.1 合作分类

| 合作类型 | 说明 | 审批层级 | 风险等级 |
|---------|------|---------|---------|
| 日常采购 | 办公用品、软件订阅 | 创始人备案 | 低 |
| 技术服务 | 开发、运维、设计 | 创始人审批 | 中 |
| 战略合作 | 深度合作、合资 | 创始人审批 | 高 |
| 客户项目 | 项目开发、服务交付 | 创始人审批 | 中 |
| 渠道合作 | 销售代理、分销 | 创始人审批 | 中 |

### 2.2 签约权限

| 签约金额 | 审批权限 | 流程 |
|---------|---------|------|
| < 1万元 | 创始人口头授权 | 简化流程 |
| 1-10万元 | 创始人书面审批 | 标准流程 |
| 10-50万元 | 创始人+LegalBrain审查 | 完整流程 |
| > 50万元 | 创始人+LegalBrain+外部律师 | 最完整流程 |

## 3. 合作流程

### 3.1 标准合作流程

```
【阶段一：需求识别】
│
├── 业务需求提出
├── 部门大脑评估可行性
├── 初步市场调研
└── 潜在合作伙伴筛选
│
【阶段二：尽职调查】
│
├── 合作伙伴背景调查
├── 资质验证
├── 信用评估
└── 案例参考
│
【阶段三：商务洽谈】
│
├── 需求确认
├── 方案讨论
├── 价格谈判
└── 合同条款协商
│
【阶段四：法务审查】
│
├── LegalBrain 合同审查
├── 风险识别
├── 条款修改建议
└── 创始人审批
│
【阶段五：签约执行】
│
├── 合同签署
├── 合作启动
├── 过程监控
└── 结果评估
```

### 3.2 简化流程 (日常采购)

```
需求提出 → 比价(≥3家) → 创始人口头授权 → 执行 → 记录归档
```

### 3.3 完整流程 (战略合作)

```
需求提出 → 尽职调查 → LegalBrain审查 → 创始人审批 → 外部律师复核 → 签约 → 执行 → 评估归档
```

## 4. 合作伙伴管理

### 4.1 合作伙伴分类

| 类别 | 说明 | 管理要求 |
|------|------|---------|
| 核心伙伴 | 年度战略合作 | 季度评估 |
| 重要伙伴 | 长期合作项目 | 半年度评估 |
| 一般伙伴 | 一次性/短期合作 | 按项目评估 |
| 备选伙伴 | 潜在合作伙伴 | 年度审查 |

### 4.2 合作伙伴评估

| 评估维度 | 权重 | 评估内容 |
|---------|------|---------|
| 资质能力 | 25% | 营业执照、行业资质、技术能力 |
| 信用状况 | 25% | 商业信用、行业口碑、履约记录 |
| 价格合理性 | 20% | 市场对比、性价比 |
| 服务质量 | 20% | 响应速度、服务态度、问题解决 |
| 发展潜力 | 10% | 行业前景、合作意愿 |

### 4.3 合作伙伴档案

记录到 L2 知识库：

```
合作伙伴档案
├── 基本信息
│   ├── 公司名称、注册信息
│   ├── 联系人、联系方式
│   └── 合作历史
│
├── 资质文件
│   ├── 营业执照
│   ├── 行业资质
│   └── 过往案例
│
├── 合作记录
│   ├── 合同列表
│   ├── 执行情况
│   └── 评估记录
│
└── 备注
    ├── 风险提示
    └── 合作建议
```

## 5. 合同管理

### 5.1 合同类型

| 合同类型 | 适用范围 | 关键条款 |
|---------|---------|---------|
| 采购合同 | 设备、软件、服务采购 | 交付、验收、付款 |
| 开发合同 | 软件开发、系统集成 | 需求、里程碑、验收标准 |
| 服务合同 | 运维、培训、咨询 | 服务范围、响应时间、SLA |
| 合作协议 | 战略合作、渠道合作 | 权利义务、分成比例 |
| 保密协议 | 涉及商业秘密 | 保密范围、期限、违约责任 |

### 5.2 合同审批

```
合同草案提交
    ↓
LegalBrain 智能审查
    ↓
├─ 低风险 → 直接通过
    ↓
├─ 中风险 → 条款修改建议
    ↓
└─ 高风险 → 标记 + 外部律师复核
    ↓
创始人审批
    ↓
签约
```

### 5.3 合同执行监控

| 监控内容 | 责任方 | 触发条件 |
|---------|--------|---------|
| 交付进度 | 部门大脑 | 里程碑延期 |
| 付款节点 | FinanceBrain | 到期前7天提醒 |
| 质量验收 | 相关部门 | 交付完成后 |
| 风险预警 | LegalBrain | 条款变更请求 |

## 6. 数字员工在合作中的应用

### 6.1 LegalBrain 辅助

- 合同模板管理
- 条款自动审查
- 风险识别
- 履约提醒

### 6.2 FinanceBrain 辅助

- 成本分析
- 付款管理
- 预算对比
- ROI 评估

### 6.3 协作流程

```
合作伙伴沟通 → LegalBrain 记录分析
    ↓
合同条款讨论 → LegalBrain 风险评估
    ↓
财务评估 → FinanceBrain 成本分析
    ↓
创始人决策 → 数字员工执行后续流程
```

## 7. 风险管理

### 7.1 风险识别

| 风险类型 | 描述 | 防控措施 |
|---------|------|---------|
| 合作方失信 | 收款后不履约 | 尽职调查 + 分期付款 |
| 合同纠纷 | 条款理解分歧 | 明确条款 + 争议解决机制 |
| 信息泄露 | 商业秘密外泄 | 保密协议 + 权限控制 |
| 过度依赖 | 对单一伙伴依赖 | 备选伙伴储备 |
| 成本超支 | 实际成本超出预算 | 预算控制 + 变更审批 |

### 7.2 应急处理

| 情况 | 处理方式 |
|------|---------|
| 合作方违约 | 依据合同条款 + 法律途径 |
| 合同变更 | 重新审批 + 记录归档 |
| 合作终止 | 资产交接 + 知识归档 |
| 争议解决 | 协商 → 调解 → 仲裁/诉讼 |

## 8. 档案与审计

### 8.1 档案管理

所有合作相关文档存储到 L2/L3 知识库：

- 合作伙伴档案
- 合同原件
- 沟通记录
- 评估报告
- 纠纷处理记录

### 8.2 审计要求

| 审计类型 | 周期 | 内容 |
|---------|------|------|
| 合同合规审计 | 季度 | 合同执行情况 |
| 合作伙伴审计 | 年度 | 合作伙伴评估更新 |
| 风险审计 | 半年度 | 风险识别与应对 |
