# 数字员工战略规划制度

**制度编号**: HR-16

**版本**: v1.0

**最后更新**: 2026-04-14

---

## 1. 目的与范围

### 1.1 目的

本制度定义企业生命智能体中数字员工的战略规划框架，包括数字员工的创建、能力发展、协作优化与生命周期管理，确保数字员工与公司战略目标一致。

### 1.2 适用范围

- 公司全体数字员工
- 数字员工编制规划
- 数字员工能力发展
- 数字员工与人类员工的协作规划

### 1.3 核心框架对应

| 核心框架 | 对应内容 |
|---------|---------|
| 《02-核心架构》§3.1 | 部门大脑架构 |
| 《03-统一员工模型》§5 | 数字员工定义 |
| 《05-进化系统》§2 | 技能生命周期 |

## 2. 数字员工战略定位

### 2.1 一人公司的数字员工价值

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      一人公司数字员工价值矩阵                                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【创始人】 ──→ 战略决策 + 数字员工管理                                    │
│       │                                                                     │
│       ├── MainBrain (战略助手)                                             │
│       │                                                                     │
│       └── 部门大脑群                                                       │
│           ├── TechBrain ──→ 技术研发能力                                   │
│           ├── OpsBrain ──→ 运营分析能力                                    │
│           ├── HrBrain ──→ 人才管理能力                                     │
│           ├── FinanceBrain ──→ 财务管理能力                                │
│           └── ...                                                            │
│                                                                             │
│  【核心价值】                                                              │
│  ├── 扩大能力边界：创始人 + 数字员工 = 虚拟团队                           │
│  ├── 提升工作效率：自动化任务处理                                         │
│  ├── 降低运营成本：无需人工工资福利                                       │
│  └── 7×24工作：数字员工可持续运转                                        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 数字员工能力层次

| 层次 | 名称 | 能力描述 | 适用场景 |
|------|------|---------|---------|
| L1 | 执行层 | 单一任务自动化 | 数据录入、文件整理 |
| L2 | 协作层 | 多任务编排协调 | 项目协作、流程处理 |
| L3 | 决策层 | 辅助决策分析 | 数据分析、方案推荐 |
| L4 | 战略层 | 战略任务执行 | MainBrain |

## 3. 数字员工编制规划

### 3.1 编制规划原则

| 原则 | 说明 |
|------|------|
| 战略对齐 | 数字员工能力应与业务战略一致 |
| 成本效益 | 评估 ROI，优先部署高价值能力 |
| 渐进式发展 | 从简单任务开始，逐步复杂化 |
| 可扩展性 | 预留能力扩展空间 |

### 3.2 部门数字员工配置

每个部门的大脑配置应包含：

```
部门大脑配置
├── MainModel: Qwen3.5-27B (部门核心推理)
├── NeuronModel: Qwen3-0.6B (闲聊响应)
├── ToolModel: Qwen3.5-2B (工具调用)
│
├── 技能列表 (Skills)
│   ├── 基础技能: 部门通用能力
│   └── 专业技能: 部门特定能力
│
├── 知识库权限
│   ├── L2: 部门知识 (读写)
│   └── L3: 全局知识 (只读)
│
└── 工具白名单 (部门授权)
```

### 3.3 编制审批流程

```
业务需求提出
    ↓
部门大脑评估可行性
    ↓
编制申请 → 创始人审批
    ↓
├─ 新技能开发 → 《05-进化系统》流程
    ↓
└─ 数字员工实例创建
    ↓
技能同步 → 上线运行
```

## 4. 数字员工能力发展

### 4.1 能力发展路径

```
【能力等级】
L1 执行 → L2 协作 → L3 决策 → L4 战略
  ↑           ↑           ↑         ↑
  │           │           │         │
  └── 基础训练 ─┘           │         │
      部门大脑学习 ──────────┘         │
          跨部门协作 ────────────────┘
              MainBrain 战略能力
```

### 4.2 技能获取方式

| 方式 | 适用场景 | 责任方 |
|------|---------|--------|
| 技能进化 | 现有能力优化 | 部门大脑 |
| 技能引入 | 新技能快速获取 | HrBrain |
| 技能融合 | 多技能组合 | 部门大脑 |
| 跨部门共享 | 通用能力复用 | MainBrain |

### 4.3 技能发展规划

| 阶段 | 目标 | 时间 |
|------|------|------|
| 基础建设 | 部门核心业务流程数字化 | 0-3月 |
| 能力扩展 | 80%日常任务自动化 | 3-6月 |
| 智能协作 | 人机协作效率最大化 | 6-12月 |
| 战略整合 | MainBrain 全局协调 | 12月+ |

## 5. 人机协作规划

### 5.1 任务分配策略

| 任务类型 | 分配给 | 原因 |
|---------|-------|------|
| 重复性任务 | 数字员工 | 效率高、错误率低 |
| 分析性任务 | 人机协作 | 结合人类判断 |
| 决策性任务 | 人类为主 | 需最终判断 |
| 创意性任务 | 人类为主 | 需原创思维 |
| 紧急任务 | 数字员工优先 | 快速响应 |

### 5.2 人机比例参考

| 部门 | 数字员工比例 | 说明 |
|------|------------|------|
| 技术部 | 70% | 大量重复开发任务 |
| 运营部 | 60% | 数据分析、用户运营 |
| 财务部 | 50% | 核算、报表自动化 |
| 客服部 | 80% | 常见问题处理 |
| 销售部 | 40% | 线索筛选、方案生成 |
| 人力资源 | 50% | 招聘筛选、培训管理 |

### 5.3 协作效率指标

| 指标 | 计算方式 | 目标值 |
|------|---------|--------|
| 自动化率 | 数字员工处理任务 / 总任务 | ≥70% |
| 人均产出 | 业务产出 / 人类员工数 | 年增长20% |
| 任务响应时间 | 从提交到完成 | <5分钟 |
| 一次通过率 | 无需返修任务 / 总任务 | >85% |

## 6. 数字员工生命周期管理

### 6.1 生命周期阶段

```
创建 → 部署 → 运营 → 优化 → 淘汰
  ↑                              │
  └──────────────────────────────┘
            持续进化
```

### 6.2 各阶段管理

| 阶段 | 关键活动 | 责任方 |
|------|---------|--------|
| 创建 | 编制审批、技能定义 | 创始人/部门大脑 |
| 部署 | 环境配置、权限开通 | 部门大脑 |
| 运营 | 任务执行、效果追踪 | 部门大脑 |
| 优化 | 技能进化、能力提升 | 《05-进化系统》 |
| 淘汰 | 能力迁移、数据归档 | 创始人审批 |

### 6.3 淘汰标准

| 淘汰条件 | 说明 | 处理方式 |
|---------|------|---------|
| 能力重复 | 与其他数字员工高度重叠 | 合并实例 |
| 效率低下 | 处理速度低于预期 | 优化或淘汰 |
| 成本过高 | 维护成本超过效益 | 评估后淘汰 |
| 战略调整 | 业务方向变更 | 能力迁移 |

## 7. 战略评估与调整

### 7.1 定期评估

| 评估周期 | 评估内容 | 责任方 |
|---------|---------|--------|
| 月度 | 运营数据、效率指标 | 部门大脑 |
| 季度 | 战略目标达成 | MainBrain |
| 半年度 | 整体能力评估 | 创始人 |
| 年度 | 下一年度规划 | 创始人 |

### 7.2 调整机制

```
评估结果 → 问题识别 → 调整方案 → 创始人审批 → 执行
```
