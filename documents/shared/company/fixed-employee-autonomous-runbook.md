# 固定数字员工自主工作流运行手册

## 目标

启用文档处理固定数字员工的自主工作流，使其可以在安全边界内自动完成分类、路由、入库建议和归档建议。

## 启用前提

- `documents/` 已挂载到服务容器
- 固定员工职责卡已经存在
- 路由配置已加载
- 人类审批通道已可用
- 审计日志已启用

## 启动步骤

1. 读取 `fixed-employee-duty-card-template.md`
2. 为每个部门固定员工加载职责卡
3. 加载 `fixed-employee-routing-config.yaml`
4. 扫描 `documents/` 目录
5. 对新文件执行分类
6. 路由到对应固定员工
7. 输出处理报告
8. 必要时触发人工审批

## 自动化边界

允许自动执行：

- 识别部门
- 识别文档类型
- 判断是否入知识库
- 判断是否归档
- 路由到对应固定员工
- 创建 Jira/OpenProject Issue（来源于 TechBrain 分配的任务）
- 更新 Issue 状态（基于员工执行进度）
- 查询 Issue 列表（用于每日汇报）

必须人工审批：

- 合同签署
- 付款执行
- 高风险权限变更
- 生产变更
- 敏感个人信息处理
- 删除 Issue
- 批量修改 Issue
- 跨部门 Issue 操作

## 失败处理

- 如果分类不确定，路由给 human_reviewer
- 如果文件路径不合法，拒绝处理
- 如果目标目录不存在，先创建目录再执行
- 如果权限不足，停止并记录审计日志

## 运行要求

- 所有处理必须可追踪
- 所有自动动作必须可回滚
- 源文件必须保留
- 知识库只存放适合复用的语义内容

## 建议的处理节奏

- 高频扫描：每 5~10 分钟
- 低频归档：每天一次
- 知识库沉淀：按需触发
- 人工复核：对高风险文件实时触发
